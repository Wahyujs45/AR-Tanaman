Kebijakan Privasi Kebun Pewarna AR

Berlaku sejak 26 September 2026 · Pengembang: Wahyu Joko Saputra, S.Pd., M.Pd., Poltekkes Kemenkes Semarang

Ringkasnya: aplikasi ini tidak mengumpulkan, menyimpan, atau mengirim data pribadi Anda. Gambar kamera diproses di ponsel Anda saja.

Apa yang dilakukan aplikasi

Kebun Pewarna AR mengenali tanaman pewarna alam melalui kamera ponsel atau label QR di papan nama tanaman, lalu menampilkan infografis tentang tanaman tersebut.

Kamera

  • Aplikasi meminta izin kamera untuk mengenali tanaman dan membaca label QR.
  • Gambar kamera diolah langsung di ponsel oleh model pengenalan yang tersimpan di dalam aplikasi.
  • Gambar tidak direkam, tidak disimpan, dan tidak dikirim ke server mana pun.
  • Anda dapat menolak atau mencabut izin kamera kapan saja melalui pengaturan ponsel. Infografis tetap bisa dibuka dari menu Koleksi.

Data yang tidak kami kumpulkan

Aplikasi tidak meminta akun, tidak memakai iklan, tidak memakai alat analitik atau pelacak, dan tidak mengakses lokasi, kontak, mikrofon, maupun berkas pribadi Anda.

Koneksi internet

Aplikasi dapat berjalan tanpa internet. Bila tersambung, aplikasi dapat mengunduh pembaruan data pengenalan tanaman dan infografis dari server pengelola kebun. Unduhan ini tidak menyertakan data tentang Anda. Seperti setiap unduhan di internet, server penyedia hosting dapat mencatat alamat IP secara teknis sesuai kebijakan penyedia tersebut.

Beberapa infografis dapat memuat tautan atau video dari layanan pihak ketiga seperti YouTube. Layanan tersebut tunduk pada kebijakan privasinya sendiri dan hanya dimuat bila Anda membuka media tersebut.

Anak-anak

Aplikasi ini aman digunakan pengunjung segala usia karena tidak mengumpulkan data pribadi apa pun.

Perubahan kebijakan

Bila kebijakan ini berubah, versi terbaru akan dimuat di halaman ini dengan tanggal berlaku yang diperbarui.
